# ÉLAN Studio — сайт косметологии и массажа

Адаптивный многостраничный сайт на HTML5, CSS3 и чистом JavaScript ES-модулями. Бэкенд — Supabase (PostgreSQL, Auth, Storage, RLS). React/Vue и сборщик не требуются.

## Возможности

- Премиальный адаптивный интерфейс в тёплой палитре, мобильная навигация и состояния фокуса.
- Каталог услуг с загрузкой из Supabase, поиском, фильтрами и сортировкой.
- Авторизация Supabase и личный кабинет.
- Онлайн-запись: услуга → специалист / любой доступный → дата → свободное время → контактные данные.
- Проверка доступности и создание записи на стороне PostgreSQL; блокировка конкурирующих бронирований и запрет пересечения записей одного специалиста.
- Панель администратора: управление услугами, специалистами, назначенными специалистам услугами, рабочими часами, статусами записей и просмотр списка клиентов.
- Политики RLS и защищённая роль администратора.
- Storage buckets для изображений услуг, специалистов и студии.

## 1. Подключить Supabase

1. Создайте проект на [supabase.com](https://supabase.com/).
2. В Supabase откройте **Project Settings → API** и скопируйте Project URL и публичный `anon`/`publishable` key.
3. В `js/config.js` вставьте значения в `SUPABASE_URL` и `SUPABASE_ANON_KEY`. В браузер можно помещать только публичный ключ. Никогда не добавляйте `service_role` key или пароль базы в код.
4. Откройте **SQL Editor** и выполните миграции строго по порядку:
   - `supabase/migrations/001_initial_schema.sql`
   - `supabase/migrations/002_booking_functions.sql`
5. Миграция №2 создаёт функции свободных слотов и создания записи, ограничение от пересечений, Storage buckets и политики. Расписание интерпретируется в часовом поясе `Europe/Berlin`; если студия в другом часовом поясе, измените его в SQL-функциях до запуска.
6. Убедитесь, что включена регистрация в **Authentication → Providers → Email**. В **Authentication → URL Configuration** задайте адрес локального сайта и продакшн URL.

## 2. Создать администратора

1. Зарегистрируйте собственный аккаунт через `auth.html` и подтвердите email, если включено подтверждение.
2. В Supabase → Authentication → Users скопируйте UUID именно своего пользователя.
3. В SQL Editor выполните запрос, заменив UUID на собственный:

```sql
insert into public.user_roles (user_id, role)
values ('ВАШ-UUID-ПОЛЬЗОВАТЕЛЯ', 'admin')
on conflict (user_id) do update set role = 'admin';
```

Не добавляйте в публичный код форму самостоятельного назначения ролей. Только доверенный владелец проекта должен назначать администраторов.

## 3. Добавить услуги, специалистов и расписание

1. Откройте `admin.html` и войдите под аккаунтом с ролью `admin`.
2. Добавьте услуги в разделе **Услуги**.
3. Добавьте специалистов в разделе **Специалисты**, затем отметьте услуги, которые каждый специалист оказывает.
4. В блоке **Рабочее расписание** добавьте часы на каждый рабочий день. Для выходного выберите день и отметьте «Выходной день».
5. Для онлайн-записи нужна как минимум одна активная услуга, активный специалист, связь специалиста с услугой и рабочие часы на выбранный день.
6. В `working_hours` задаётся один рабочий интервал на специалиста и день через интерфейс. Перерыв можно завести в `breaks` вручную; он исключается из доступных слотов.

Цены хранятся в EUR. Для другой валюты обновите отображение цены и данные услуг последовательно во всех страницах.

## 4. Локальный запуск

Из папки проекта запустите статический сервер (ES-модули нельзя корректно открывать напрямую через `file://`):

```bash
python -m http.server 5500
```

Откройте `http://localhost:5500`. Также можно использовать расширение Live Server в VS Code.

## 5. Публикация на GitHub и в интернете

1. Создайте новый пустой репозиторий GitHub.
2. В корне проекта выполните:

```bash
git init
git add .
git commit -m "Build ÉLAN Studio website"
git branch -M main
git remote add origin https://github.com/ВАШ-АККАУНТ/ВАШ-РЕПОЗИТОРИЙ.git
git push -u origin main
```

3. Для статического сайта подойдут GitHub Pages, Netlify или Cloudflare Pages. В настройках хостинга укажите корень проекта как publish directory; команда сборки не требуется.
4. В Supabase → Authentication → URL Configuration добавьте точный URL опубликованного сайта в Site URL / Redirect URLs.
5. Проверьте формы входа, восстановления пароля, запись, админ-панель и RLS уже на опубликованном домене.

## 6. Безопасность и контрольный список перед запуском

- Не публикуйте реальные контакты клиентов, ключи и данные доступа в GitHub.
- В браузере используйте только публичный ключ Supabase; безопасность обеспечивают RLS и серверные функции.
- RLS должен оставаться включённым на всех таблицах, доступных через API.
- Функция `create_appointment` валидирует ввод и повторно проверяет свободное время при создании. Ограничение PostgreSQL не позволяет создать пересекающиеся записи для одного специалиста.
- Настройте CAPTCHA/rate limiting для публичных форм, резервное копирование и мониторинг.
- Проверьте политику конфиденциальности, согласие на обработку персональных данных и реальные контактные сведения перед запуском.
- Прогоните сценарии: два одновременных запроса на один слот, отмена записи, выходной, перерыв, неактивная услуга, обычный пользователь в `admin.html`, доступ к чужим записям.
- Публичные демо-карточки услуг используются только как fallback, если база ещё не настроена; они не создают настоящие записи.

## Структура

- `index.html`, `services.html`, `service.html`, `booking.html`, `about.html`, `contacts.html`, `auth.html`, `account.html`, `admin.html`, `privacy.html`
- `css/` — основной стиль, шапка, футер, компоненты и адаптивные правила
- `js/` — модули интерфейса, авторизации, услуг, записи и админ-панели
- `supabase/migrations/` — SQL-схема, RLS и функции записи
- `supabase/functions/create-appointment/` — необязательная Edge Function для проксирования создания записи

## Что нужно сделать владельцу проекта

Supabase нельзя фактически подключить к вашему облачному проекту без URL и публичного ключа; в архиве они намеренно оставлены пустыми. После настройки проекта и применения миграций сайт обращается к реальной базе. Перед публичным запуском обязательно выполните контрольный список безопасности и тесты выше.
